# Sales Data Cleaning Using Python and Pandas

## Project Overview
A Python data-cleaning project using a synthetic sales dataset.

## Tools
Python, Pandas, NumPy, Matplotlib, Jupyter Notebook

## Data Cleaning Tasks
- Removed duplicate records
- Standardised customer names and email addresses
- Cleaned inconsistent product names
- Converted prices and quantities into numeric values
- Standardised date formats
- Identified missing and invalid values
- Created data quality and exception reports

## Results
- Original records: 38
- Cleaned records: 35
- Duplicate records removed: 3
- Remaining exact duplicates: 0
- Missing unit prices: 2
- Missing quantities: 1
- Missing order dates: 1

Missing transaction values were flagged, not invented.

Install Python, Pandas, NumPy and Matplotlib.
Open the Jupyter Notebook and run its cells in order.
